cooperative_cashflow_ar
=======================

The Tryton *cooperative_cashflow_ar* module.

# Overview

Tryton module to manage cash flow projections for cooperatives in Argentina.
It provides projection capabilities for:

- Sale invoices (ventas a crédito)
- Purchase invoices (compras proveedores)
- Receipt batches (lotes de cobros/pagos)
- Cash flow reporting with FODT templates
